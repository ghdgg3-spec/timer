# 평가위원회 타이머

발표·평가 진행용 대형 타이머입니다. 별도 설치 없이 브라우저에서 동작합니다.

## 주요 기능

- **전체화면 모드** — 우측 상단 버튼 또는 `F` 키. 전체화면에서는 몇 초 후 버튼과 커서가 자동으로 숨겨지고, 마우스를 움직이면 다시 나타납니다.
- **종소리 알림** — 종료 5분 전(땡 1번), 1분 전(땡 2번), 종료 시(땡 3번). 설정에서 각각 켜고 끌 수 있습니다(1분 전만 / 5분 전만 / 둘 다 / 모두 끔). 음량 조절과 테스트 버튼, 전체 음소거(`M`)도 있습니다.
- **여러 화면 동기화** — 설정에서 같은 **위원회 코드**를 입력해 연결하면, 코드가 같은 모든 화면에서 시작·일시정지·초기화·시간 변경이 함께 움직입니다.
  - `server.js` 실행 중: 다른 PC·태블릿 등 기기 간 동기화
  - 서버 없이 정적 파일로 열었을 때: 같은 브라우저의 탭 간 동기화
- **시간 클릭으로 조작** — 시작/일시정지/초기화 아이콘 버튼이 있고, 가운데 큰 시간 숫자를 클릭해도 시작/일시정지가 됩니다.
- **임박 시 색상 경고** — 5분 전 주황, 1분 전 빨강, 10초 전 깜빡임, 종료 후 빨간 깜빡임(끄기 가능).
- **화면 꾸미기** — 글씨 굵기(5단계), 글씨 색, 배경 색을 자유롭게 변경. 테마 프리셋(다크/블랙/화이트/네이비/그린) 제공. 설정은 브라우저에 저장됩니다.
- **기본 기능** — 시간 프리셋(5/10/15/20/30/45/60분), 분·초 직접 입력, 진행 중 ±1분 조정, 진행률 바, 종료 후 초과 시간(+MM:SS) 표시, 진행 중 화면 꺼짐 방지(Wake Lock), 탭 제목에 남은 시간 표시.

## 단축키

| 키 | 기능 |
|---|---|
| `Space` | 시작 / 일시정지 |
| `R` | 초기화 |
| `F` | 전체화면 |
| `↑` / `↓` | 1분 늘리기 / 줄이기 |
| `M` | 소리 켜기 / 끄기 |

## 실행 방법

### 1) 기기 간 동기화까지 사용 (권장)

```bash
npm install
npm start        # http://localhost:3000 (PORT 환경변수로 변경 가능)
```

같은 네트워크의 다른 기기에서는 `http://<서버IP>:3000` 으로 접속한 뒤, 설정에서 같은 위원회 코드를 입력하면 됩니다. 코드는 해시 처리되어 원문이 서버로 전송되지 않습니다.

### 2) 서버 없이 사용

`index.html` 파일을 브라우저로 열거나 GitHub Pages 등 정적 호스팅에 올리면 됩니다. 이 경우 동기화는 같은 브라우저의 탭 사이에서만 동작합니다.

> 종소리는 브라우저 정책상 화면을 한 번 클릭(터치)한 뒤부터 재생됩니다.
