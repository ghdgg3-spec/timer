# 평가위원회 타이머

발표·평가 진행용 대형 타이머입니다. 별도 설치 없이 브라우저에서 동작합니다.

## 주요 기능

- **전체화면 모드** — 우측 상단 버튼 또는 `F` 키. 전체화면에서는 몇 초 후 버튼과 커서가 자동으로 숨겨지고, 마우스를 움직이면 다시 나타납니다.
- **종소리 알림** — 종료 5분 전, 1분 전, 종료 시 각각 짧고 굵은 "땡" 한 번. 설정에서 각각 켜고 끌 수 있습니다(1분 전만 / 5분 전만 / 둘 다 / 모두 끔). 음량 조절과 테스트 버튼, 전체 음소거(`M`)도 있습니다.
- **여러 화면 동기화** — 설정에서 같은 **위원회 코드**(예: `1234`, 매일 바꿔도 됨)를 입력해 연결하면, 코드가 같은 모든 화면에서 시작·일시정지·초기화·시간 변경이 함께 움직입니다. 세 단계로 자동 대체됩니다.
  1. Firebase 설정을 등록해두면: **어느 장소·어느 네트워크에 있는 컴퓨터끼리도** 인터넷을 통해 동기화 (권장)
  2. Firebase 설정이 없고 `server.js` 실행 중이면: 같은 네트워크의 다른 PC·태블릿 간 동기화
  3. 둘 다 없으면: 같은 브라우저의 탭 간 동기화
- **시간 클릭으로 조작** — 시작/일시정지/초기화 아이콘 버튼이 있고, 가운데 큰 시간 숫자를 클릭해도 시작/일시정지가 됩니다.
- **임박 시 색상 경고** — 5분 전 주황, 1분 전 빨강, 10초 전 깜빡임, 종료 후 빨간 깜빡임(끄기 가능).
- **화면 꾸미기** — 글씨 굵기(5단계), 글씨 색, 배경 색을 자유롭게 변경. 테마 프리셋(다크/블랙/화이트/네이비/그린) 제공. 설정은 브라우저에 저장됩니다.
- **키보드로 시간 직접 입력** — 화면에서 숫자키를 누르면 휴대폰 타이머처럼 오른쪽부터 채워집니다. 예: `1`→`5`→`0`→`0` = 15:00, `1`→`3`→`0` = 1:30. `Enter` 적용, `Space` 적용 후 바로 시작, `Backspace` 지우기, `Esc` 취소.
- **기본 기능** — 시간 프리셋(5/10/15/20/30/45/60분), 분·초 직접 입력, 진행 중 ±1분 조정, 진행률 바, 종료 후 초과 시간(+MM:SS) 표시, 진행 중 화면 꺼짐 방지(Wake Lock), 탭 제목에 남은 시간 표시.

## 단축키

| 키 | 기능 |
|---|---|
| `0`~`9` | 시간 직접 입력 (`Enter` 적용 · `Space` 적용 후 시작 · `Esc` 취소) |
| `Space` | 시작 / 일시정지 |
| `R` | 초기화 |
| `F` | 전체화면 |
| `↑` / `↓` | 1분 늘리기 / 줄이기 |
| `M` | 소리 켜기 / 끄기 |

## 실행 방법

### 1) 인터넷으로 어디서든 동기화 (Firebase, 권장)

서버를 직접 켜두지 않아도 되고, 완전히 다른 장소·다른 네트워크의 컴퓨터끼리도 동기화됩니다. `index.html`만 열면 되므로 GitHub Pages 등 정적 호스팅에 올려도 그대로 동작합니다.

1. [console.firebase.google.com](https://console.firebase.google.com/) 에서 무료 프로젝트를 만듭니다.
2. 왼쪽 메뉴 **빌드 → Realtime Database** → "데이터베이스 만들기" (테스트 모드로 시작하면 별도 설정 없이 바로 됩니다)
3. **프로젝트 설정 → 내 앱 → 웹 앱 추가**를 누르면 나오는 `firebaseConfig = { ... }` 객체 전체를 복사합니다.
4. 타이머 화면에서 설정(⚙) → "여러 화면 동기화" 맨 아래 칸에 붙여넣고 **저장**을 누릅니다. (같은 브라우저에 저장되므로, 사용하는 모든 컴퓨터에서 한 번씩 붙여넣어야 합니다.)
5. 이후 각 컴퓨터에서 같은 위원회 코드(예: `1234`)를 입력해 **연결**하면 동기화됩니다.

> Firebase 설정값은 클라이언트에 노출되는 것이 정상입니다(비밀키 아님). 다만 테스트 모드 데이터베이스는 누구나 읽고 쓸 수 있으므로, 위원회 코드처럼 예측하기 어려운 값을 방 이름으로 쓰는 것을 권장하며 민감한 정보는 저장하지 않습니다.

### 2) 같은 네트워크 안에서만 동기화 (자체 서버)

```bash
npm install
npm start        # http://localhost:3000 (PORT 환경변수로 변경 가능)
```

같은 네트워크의 다른 기기에서는 `http://<서버IP>:3000` 으로 접속한 뒤, 설정에서 같은 위원회 코드를 입력하면 됩니다(Firebase 설정을 등록하지 않은 경우에 사용됩니다). 코드는 해시 처리되어 원문이 서버로 전송되지 않습니다.

### 3) 서버 없이 사용

`index.html` 파일을 브라우저로 열거나 GitHub Pages 등 정적 호스팅에 올리면 됩니다. Firebase 설정도, 서버도 없다면 동기화는 같은 브라우저의 탭 사이에서만 동작합니다.

> 종소리는 브라우저 정책상 화면을 한 번 클릭(터치)한 뒤부터 재생됩니다.
